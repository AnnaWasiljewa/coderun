### Средний элемент

Рассмотрим три числа _a, b_ и _c_. Упорядочим их по возрастанию.

Какое число будет стоять между двумя другими?

__Формат ввода__  
В единственной строке записаны три целых числа _a, b_ и _c_ (−1000 ≤ _a,b,c_ ≤ 1000), числа разделены одиночными пробелами.

__Формат вывода__   
Выведите число, которое будет стоять между двумя другими после упорядочивания.
```py
numbers = list(map(int, input().split()))
sorted_numbers = sorted(numbers)
print(sorted_numbers[1])
```
