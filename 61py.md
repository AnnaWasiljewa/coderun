### Пересечение множеств

Даны два списка чисел, которые могут содержать до 10000 чисел каждый. Выведите все числа, которые входят как в первый, 
так и во второй список в порядке возрастания.

__Формат ввода__  
Вводятся два списка целых чисел. Все числа каждого списка находятся на отдельной строке.

Самое простое решение превышает лимит памяти:
```py
set_a = set(map(int, input().split()))
set_b = set(map(int, input().split()))
set_a &= set_b
print(*sorted(set_a))
```

Проходит с использованием итератора, считываем и сравниваем «на лету»:
```py
set_a = set(map(int, input().split()))
result = set()
for num in map(int, input().split()):
    if num in set_a:
        result.add(num)
        
print(*sorted(result))
```
