[Простая подсказка](https://coderun.yandex.ru/problem/simple-suggest/description)

```
n = int(input())
dct = {}                         #создаю словарь
for i in range(n):
    word = input()  
    if word[0] not in dct:       #если слова нет в словаре, добавляю
        dct[word[0]] = 1
    dct[word[0]] += 1
max_key = max(dct, key=dct.get)  #узнаю ключ максимального значения
print(max_key)
```
