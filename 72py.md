### Возрастает ли список?

Дан список. Определите, является ли он монотонно возрастающим (то есть верно ли, что каждый элемент 
этого списка строго больше предыдущего).

Выведите _YES_, если массив монотонно возрастает и _NO_ в противном случае.

```py
numbers = list(map(int, input().split()))
len_nums = len(numbers)
flag = True

for i in range(len_nums-1):
    if numbers[i] >= numbers[i+1]:
        flag = False
        break
    
if flag:
    print("YES")
else:
    print("NO")
```
